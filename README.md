# The Decision Room · Finance Pulse

Public archive of @aniyameysa's Finance Pulse stories and charts.

Every piece carries a serial number (FP-0001, FP-0002, ...) printed in its footer.
The commit date of each file here is the public record of when it was first published.

- `archive/FP-XXXX.png` — each piece, by serial number
- `stories/YYYY-MM-DD/` — daily stories as scheduled
- `serial.txt` — the last serial number used
